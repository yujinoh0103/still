# 스틸 (미완성)

> **"밤새는 건 힘들지만... 내가 하고 싶은 일을 한다는 건 정말 행복해!"**
> 하지만 그 행복은 낯선 폐가 앞에서 공포로 변하기 시작합니다.

신입 경찰 '현'의 시점에서 펼쳐지는 1인칭 스릴러/어드벤처 게임 **스틸**입니다. 퇴근길, 갑작스러운 연료 부족으로 멈춰 선 차, 그리고 눈앞에 나타난 의문의 폐가. 당신은 이곳에서 무사히 집으로 돌아갈 수 있을까요?

---

## 🎮 Game Preview

* **장르:** 공포, 스릴러, 어드벤처
* **플랫폼:** PC (Windows)
* **시놉시스:** 경찰 임용 3개월 차 신입 '현'. 열정 가득한 야근 후 퇴근길에 오르지만, 인적이 드문 도로 위에서 기름이 떨어져 고립됩니다. 어둠 속에 홀로 남겨진 현의 눈앞에 으스스한 폐가가 모습을 드러내고, 그곳으로 발걸음을 옮기게 됩니다.
